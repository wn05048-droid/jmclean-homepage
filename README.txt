JMclean 4차: 이메일/카카오톡 선택형 문의 페이지
1. index.html을 GitHub 저장소 최상위에 업로드하여 기존 파일을 교체합니다.
2. 카카오톡 채널 개설 후 index.html의 KAKAO_CHANNEL_URL=''에 실제 채널 URL을 넣습니다.
3. 이메일 자동 접수는 /api/inquiry 서버 엔드포인트가 필요합니다. 이 파일만으로 이메일이 자동 발송되지는 않습니다. 미설정 상태에서는 오류를 표시합니다.
4. 운영 전 개인정보 처리방침과 보유기간을 확정하고 동의 문구를 수정해야 합니다.
5. 사진은 임시 외부 이미지로 추후 교체할 수 있습니다.
